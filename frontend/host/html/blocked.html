Maintainer's Copilot — blocked-origin demo

Serve this page from an origin that is not in the widget's allowed_origins (for example open it via a different host/port). The loader's fetch for the widget config is rejected by CORS (the API only returns Access-Control-Allow-Origin for allowed origins), so the widget never renders and the browser console shows a clear error — failing safe without breaking this page.

Open the console: you should see a CORS error and the loader's could not load widget (origin not allowed …) message.
