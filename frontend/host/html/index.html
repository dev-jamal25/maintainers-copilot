Maintainer's Copilot — allowed-origin demo

This page is the allowed origin. Its origin (e.g. http://localhost:8080) must be in the widget's allowed_origins (set by an admin in the Streamlit app). The widget config fetch then succeeds (CORS) and the chat bubble loads in the bottom corner.

Set the widget id below (the admin-created w_… id) and the API base, then reload. Open the browser console to see the loader logs.
